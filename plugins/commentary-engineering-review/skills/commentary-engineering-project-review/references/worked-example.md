# Engineering Project Review example

Read the [portable workflow source](https://github.com/commentary-dev/commentary-skills/tree/main/examples/projects) for the evidence fixture and CLI-capable/MCP-only adapters. Version 0.1.0 is tested with Projects Contract v1, CLI 0.2.0 and Agent SDK 0.2.0. The fixture validates requests and recovery; it is not live provider, browser isolation or genuine human acceptance evidence.

The executable fixtures preserve exact versions and report awaiting_human. Use the deployed schemas for real identifiers and upload limits.

## Exact workflow

The evidence workflow pins provider/resource/commitSha/capturePolicy/selectedPaths, composes exact targets, creates expectedOutcomeMarkdown/acceptanceScope and attaches report/result. A passing report is still reported. For multiple PRs preserve all original exact targets. Request verification with discovered project_evidence.verification_request and read results; do not fetch arbitrary agent-supplied URLs as proof.
